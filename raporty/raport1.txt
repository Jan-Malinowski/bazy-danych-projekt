Pomysł - Baza danych domu maklerskiego zawierająca informacje o pracownikach, klientach, spółkach oraz o zakupach i sprzedażach akcji tych spółek. 


Tabele w bazie danych:

Employees:
	-id_emp: INT - id pracownika (PRIMARY KEY)
	-name: VARCHAR - imie
	-surname: VARCHAR - nazwisko
	-date_of_birth: DATE - data urodzenia pracownika
	-account: VARCHAR - numer konta bankowego pracownika (28 SIGNS)
	-base_salary: DECIMAL(12, 2) - podstawowa stawka pracownika (>0)
	-prov: DECIMAL(12, 2) - zarobione pieniądze przez pracownika podczas roku (>=0)
Transactions:
	-id_trans: INT - id sprzedarzy (PRIMARY KEY)
	-id_emp: INT - id pracownika (FOREIGN KEY)
	-id_clt: INT - id klienta (FOREIGN KEY)
	-ticker: VARCHAR - nazwa sprzedanych/kupionych akcji
	-stock_amm: INT - ilość kupowanych/sprzedawanych akcji (>0)
	-trans_type: BOOL - 0 jeżeli zakup akcji, 1 jeżeli sprzedaż
	-cost: DECIMAL(10, 2) - cena całej transakcji
	-trans_time: TIMESTAMP - data transakcji
Stocks:
	-ticker: VARCHAR - nazwa akcji (CAPITAL LETTERS) (PRIMARY KEY)
	-comp_name: VARCHAR - nazwa firmy danej akcji
	-curr_price: DECIMAL(12, 2) - aktualna cena akcji
	-amm: INT - ilość akcji dostępnych do zakupu (>=0)
Clients:
	-id_clt: INT - id klienta (PRIMARY KEY)
	-name:  VARCHAR - imie klienta
	-surname: VARCHAR - nazwisko klienta
	-pesel: VARCHAR - pesel klienta
	-tel: VARCHAR - numer telefonu klienta
	-country: VARCHAR - kraj pochodzenia klienta
	-account: VARCHAR - numer konta bankowego klienta (28 SIGNS)
History:
	-ticker_id: VARCHAR - (PRIMARY KEY)
	-ticker: VARCHAR - nazwa akcji (CAPITAL LETTERS)
	-price_date: TIMESTAMP - data
	-price: DECIMAL(12, 2) - cena akcji podczas konkretnego dnia (>0)
